البيانات التي تصل إليها

بإذن صاحب القناة عبر حساب Google، تستعمل الأداة واجهة YouTube Data API للوصول إلى: قائمة فيديوهات القناة ومسوداتها (العنوان، والوصف، والوسوم، واسم الملف، وحالة الخصوصية، وموعد النشر)، والبثوث المباشرة ومفاتيح البث، وذلك لجدولة الفيديوهات وتجهيز البثوث وتعديل معلوماتها.

كيف تُستعمل وتُحفظ

  • تُستعمل البيانات فقط لتنفيذ ما يطلبه صاحب القناة على قناته.
  • تُحفظ على جهاز صاحب القناة وحده، ورموز الإذن مشفّرة.
  • تُرسل تنبيهات موجزة (اسم القناة وعناوين الفيديوهات ومواعيدها) إلى حساب تيليجرام الخاص بصاحب القناة.
  • لا تُباع البيانات ولا تُشارك مع أي طرف، ولا تُستعمل للإعلانات أو لتدريب نماذج الذكاء الاصطناعي.

إلغاء الإذن وحذف البيانات

Privacy Policy — Atr Scheduler / Atr Live

Last updated: September 26, 2026

Who uses this tool

This is a private tool used solely by the owner of the "Atr Al-Kalam" network to manage his own YouTube channels. No other users sign up or use it.

Data accessed

With the channel owner's authorization through Google OAuth, the tool uses the YouTube Data API to access the channel's videos and drafts (title, description, tags, original file name, privacy status and publish time), and its live broadcasts and stream keys, in order to schedule videos, prepare broadcasts and update their metadata.

How data is used and stored

  • Data is used only to perform actions the channel owner requests on his own channels.
  • Data is stored only on the owner's computer; OAuth tokens are stored encrypted.
  • Short notifications (channel name, video titles and times) are sent to the owner's own Telegram account.
  • Data is never sold or shared with third parties, and is not used for advertising or to train AI models.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services, subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Stored data is deleted by removing it from the owner's computer.
